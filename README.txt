TOBI CLIENT WEBSITE — QUICK START

PREVIEW:
1. Extract the ZIP.
2. Open the TOBI_CLIENT_WEBSITE folder.
3. Double-click index.html. Use the top navigation for the other pages.

PUBLISH FREE WITH GITHUB PAGES:
1. Create/sign in to GitHub and create a PUBLIC repository (example: tobi-client-website).
2. Upload all files and folders inside this folder (not the ZIP itself).
3. Open repository Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. GitHub will show your published website URL on that Pages screen.

BEFORE SHARING:
- Edit community.html and replace the placeholder Discord, YouTube and support links.
- Edit download.html and add a real, tested public download URL when your desktop build is ready.
- Update feature descriptions to match features actually available in your app.

IMPORTANT:
This is a static website starter. It does not include the TOBI desktop app, user accounts,
automatic updater, server/database, or installer hosting. The download button is intentionally
disabled until you add a real release URL. Google Fonts load online; fallback fonts are included.
